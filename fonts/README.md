# Fonts

The two typefaces used everywhere on the menu, from Google Fonts. Both are free under the SIL Open Font License (the `OFL-*.txt` files): they can be installed, embedded, and shared with anyone.

| File | Used for |
| --- | --- |
| `ZillaSlab-Medium.ttf`, `ZillaSlab-SemiBold.ttf`, `ZillaSlab-Bold.ttf` | Titles, section headings, item names, prices |
| `LibreFranklin-Regular.ttf`, `-Italic.ttf`, `-Medium.ttf`, `-SemiBold.ttf` | Descriptions, notes, labels, footers |

**You don't need these to print a PDF from `print/`.** The PDFs carry their fonts inside them.

Install them when you want to edit: the Word file (it embeds its fonts, but Word on a Mac edits more reliably with them installed), or new material such as a specials sheet. On a Mac, select all seven `.ttf` files, double-click, and choose Install in Font Book. On Windows, select them, right-click, and choose Install.

`tools/word/fonts/` holds trimmed, renamed copies made for the Word build; use the ones here for installing.
