# Proposed menu: proof prints

DRAFT for review. These are the "Proposed new menu (draft)" page of the design canvas, rendered for printing and passing around. They are not the live menu; `print/TKB-Diner-Menu.pdf` still is. Sources are in `design/proposed/`.

Every font is embedded in these PDFs, so nothing needs installing to print them. Print at **100% / Actual size** (not "Fit to page"), with no scaling.

| File | Paper | How to print |
| --- | --- | --- |
| `TKB-Diner-Menu-PROPOSED.pdf` | 6 pages, US Letter | One-sided, one page per sleeve, same as the current menu. |
| `Drink-Card-half-letter-2up-on-Letter.pdf` | 2 sheets, US Letter landscape | Two cards per sheet. Print double-sided, flip on short edge, then cut down the middle. Sheet 1 is the Specialty Drinks front, sheet 2 the Build Your Drink back. |
| `Drink-Card-half-letter.pdf` | 2 pages, 5.5 × 8.5 in | The same card at its actual size, for printers that take half-letter paper. |
| `Drink-Card-4x6.pdf` | 2 pages, 6 × 4 in (landscape) | For pre-cut 4 × 6 index cards. Set the paper size to 4 × 6 in, landscape. Most printers can't print both sides of an index card automatically: print page 1, put the cards back in the tray, and print page 2. Test one card first to see which way to turn them. |
