A section name with a rule running to the end of the column, plus an optional serving note.

- Provide: the section name; optionally one italic note that applies to every item below.
- Heading in `section-heading` (ink, 23px) followed by a 2px `ink` rule filling the column. Note in `note` (italic, ink-muted) directly under it.
- Leave about 8px extra space above a heading that follows another section in the same column.
- Don't: put prices in a heading, or repeat the note on each item.
