The basic priced line: name, dotted leader, price, and an optional description underneath.

- Provide: name (Title Case), price (numbers only, no $), optional description (sentence case, no full stop).
- Name in `item-name`, price in `price` (maroon), leader a 2px dotted `leader` line with `leader-gap` either side, description in `description` (ink-soft).
- Stack items with `item-gap`. The price aligns to the right edge of the column.
- Size options read "half 5 · full 10"; two unexplained prices read "9 / 12".
- Don't: wrap the name to two lines, put the price in the description, or add a dollar sign.
