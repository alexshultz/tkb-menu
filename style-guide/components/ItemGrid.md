MenuItems running two-up across the full page width.

- Provide: a list of items; with or without descriptions.
- Two equal columns `column-gap` apart, `grid-row-gap` between rows (or `item-gap` when items have descriptions). Order runs left to right, then down.
- Use when a section has many short items (appetizers, burgers) so it doesn't run down one column.
- Don't: mix items with and without descriptions in one grid.
